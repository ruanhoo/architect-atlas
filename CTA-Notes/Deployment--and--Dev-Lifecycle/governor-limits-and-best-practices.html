Sharing & Relationships

Official docs: Sharing Rules · Increase the Maximum Number of Sharing Rules per Entity · Platform Sharing Architecture

Sharing rules extend access beyond OWD. Limits are per object (entity). Guest user sharing rules are a special criteria-based type and count toward the criteria-based cap.

LimitDefaultMax via SupportSource
All sharing rules (owner-based + criteria-based) per object300500KB 000384485
Criteria-based sharing rules only per object50200same

Editions for increase request: Professional, Enterprise, Performance (Unlimited), Developer.

Performance note (from KB): Too many sharing rules can slow inserts/updates — review existing rules before requesting an increase.

Check current usage:

  • Lightning: Setup → Object Manager → object → Object Limits
  • Classic: Setup → Customize → object → Limits
  • Look at Usage for:
    • Sharing Rules (Both Owner- and Criteria-based)
    • Sharing Rules (Criteria-based Only)

To increase: System Admin submits a limit increase request with Support.
